# CHIFOUMI

A rock-paper-scissors (Chifoumi) web app in Java EE, built for the ENI course "Le developpement Web cote serveur - BackEnd avec Java Enterprise Edition (JEE)" (Module 3 - JSP).

## About The Project

The application (TPChifoumi) lets a user play rock-paper-scissors against the server in a single round. It is composed of a JSP page to play, a JSP page displaying the result (what the user played, what the server played and who won) with a replay button, and a servlet performing the processing. Built as a Dynamic Web Project following the course assignments ([Module 3 statements](https://github.com/Dyrits/CHIFOUMI/tree/master/Module%2003%20-%20Enonc%C3%A9s%20TP)).

### Built With

- Java EE (JSP, Servlets)

## Getting Started

Deploy the Dynamic Web Project on a servlet container (e.g. Tomcat).
